# i3 window manager

Configuration lives in two files (the second is `include`d by the first):

- `.config/i3/config` - core bindings, theme variables, workspaces, modes.
- `.config/i3/mystuff` - personal additions (autostart, scratchpad, display switching, power).

## Mod key

`Mod4` (Super).

## Keybindings

| Keys | Action |
| --- | --- |
| `Mod+Enter` | terminal (kitty) |
| `Mod+d` / `Mod+])` | rofi app launcher (`drun`) |
| `Mod+Tab` | rofi window switcher |
| `Mod+.` | rofi emoji picker |
| `Mod+j/k/l/;` and arrows | focus direction |
| `Mod+Shift+j/k/l/;` and arrows | move window |
| `Mod+h` / `Mod+v` | split horizontal / vertical |
| `Mod+f` | fullscreen toggle |
| `Mod+s` / `Mod+w` / `Mod+e` | layout stacking / tabbed / toggle split |
| `Mod+Space` / `Mod+Shift+Space` | focus floating / floating toggle |
| `Mod+a` | focus parent |
| `Mod+r` | resize mode (j/k/l/; or arrows, Enter/Esc to leave) |
| `Mod+1..0` / `Mod+Shift+1..0` | switch / move to workspace |
| `Mod+Escape` | scratchpad toggle (hidden kitty) |
| `Mod+Shift+Escape` | send focused window to scratchpad |
| `Mod+Shift+d` | cycle display layout (external/internal/mirror/extended) |
| `Mod+Shift+f` | recover: force internal display |

| `Mod+Shift+x` | lock immediately |

## Workspaces

Named with Nerd Font icons: `1: Brave`, `2: Chrome`, `3: Term`, `4: Code`,
`5: Chat`, `6: Music`, `7: Files`, `8: Gear`, `9: Home`, `10: Work`.
App assignment rules route Brave, Chrome and Hubstaff to their workspaces.

## Theme colors

A One Dark palette is defined as `set $...` variables at the top of `config`
and applied to borders and focus. The same palette is reused by polybar, rofi,
dunst and picom (see [theming.md](theming.md)).

## Scratchpad

A kitty instance with class `scratchpad` is started hidden at login and moved to
the scratchpad by a `for_window` rule. `Mod+Escape` toggles it.

## Autotiling

`autotiling` (a small python daemon) automatically chooses the split direction
based on window dimensions, so `Mod+h` / `Mod+v` are mostly unnecessary.
